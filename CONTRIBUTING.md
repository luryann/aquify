# Contributing

## Workflow

1. Read `CLAUDE.md`, `TODO.md`, and `SYSTEM.md` before starting work.
2. Keep changes scoped to the active TODO step.
3. Update `TODO.md` checkboxes as tasks are completed.
4. Amend `CLAUDE.md` when architecture, structure, or conventions change.

## Standards

- Keep API and UI behavior aligned with `docs/planning/Developer Handoff Master Document.txt`.
- Preserve locked decisions from `DECISIONS.md` and `docs/decisions/*`.
- Add docs updates with any behavior or structure changes.

## Verification

- Run local checks relevant to your change.
- Include enough notes in PR descriptions for reproducibility.
