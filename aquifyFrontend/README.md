# aquify marketing site

Static HTML/CSS/JS. No build step is needed to view it.

- Preview: `python3 -m http.server 4400`, then open http://localhost:4400
- Pages are generated by `tools/site.py` (shared nav, footer and page bodies live there). After editing copy: `python3 tools/site.py`
- Scroll engine: `assets/main.js`. Pinned stages write `--p`/`--t` CSS variables, the hero water is a WebGL shader, and statements reveal word by word.
- Screenshots in `assets/img/` come from the real admin app running on synthetic demo data (a made-up club).
- Waitlist form posts JSON to `/api/waitlist` (or the form's `data-endpoint`). Wire it to your backend or a form service before launch.
- Type: Helvetica Neue where installed, bundled Inter Tight elsewhere.
- Rule: no invented pricing, customers, testimonials or stats. Claims must match what the app does.
